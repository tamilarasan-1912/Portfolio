## Run Locally

Requirements: **Node.js 20+**

```bash
git clone https://github.com/tamilarasan-1912/Portfolio.git
cd Portfolio
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Deployment

The recommended deployment platform is Vercel. Connect the GitHub repository to Vercel and use:

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
